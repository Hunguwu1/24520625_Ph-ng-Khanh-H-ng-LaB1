Giới thiệu

Tôi là Phung Khanh Hung, sinh viên Công nghệ thông tin. Tôi đang học xây dựng website bằng HTML, CSS và JavaScript.

Kỹ năng

HTML và CSS

  • Đang học cách xây dựng trang bằng HTML semantic.
  • Thực hành bố cục responsive với Flexbox và Grid.
  • Sử dụng biến CSS để quản lý màu sáng và tối.

JavaScript cơ bản

  • Thực hành xử lý sự kiện với addEventListener.
  • Cập nhật nội dung và trạng thái trên trang.
  • Lưu lựa chọn theme bằng localStorage.

Công cụ phát triển

  • Viết và chỉnh sửa mã trong Visual Studio Code.
  • Thực hành quản lý phiên bản với Git và GitHub.
  • Kiểm tra giao diện và lỗi bằng Chrome DevTools.
