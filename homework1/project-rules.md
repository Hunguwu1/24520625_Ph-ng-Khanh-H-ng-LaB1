# Project Rules

- Use only HTML, CSS, and JavaScript.
- Run the website through a local HTTP server.
- Use semantic HTML, no div elements, one h1, and a skip link.
- Add image alt text and visible form labels.
- Use CSS color variables and a border-box reset.
- Make the page fit a 375px screen without horizontal scrolling.
- Save the theme using localStorage key theme.
- Use addEventListener, not inline event handlers.
- Use textContent for user text.
- Check accessibility, keyboard navigation, CSP, and performance.
- Implement, test, and commit one task at a time.
- Do not commit passwords or temporary files.
